# Antipodal-only transport controls

Six prescribed-worldtube route tests, not force-driven mouth trajectories.
Every JSON retains the initial front, exact input histories, surface and throat
legs, aperture maps, and an explicit unresolved termination status.

Surface legs interact only at the antipodal endpoint. Throat legs use proper
clock matching. A cycle or unavailable future/past history is not absorption.

Regenerate with `python -m experiments.closure_ledger.antipodal_throat_replay`.
The HTML replay is self-contained. See `docs/antipodal_throat_transport.md` for
the model rule, test controls, and limits on physical interpretation.
